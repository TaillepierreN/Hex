# Hex

**Hex** is a Unity 3D prototype inspired by turn-based tactical games (XCOM-like).  
It is primarily a learning project, built to explore and improve my understanding of tactical gameplay systems, hex grids, and Unity development practices.

This repository reflects an iterative development process focused on experimentation, refactoring, and skill progression rather than a finished commercial product.

---

## Project Overview

The project focuses on implementing and experimenting with core mechanics commonly found in tactical strategy games, including:

- Hexagonal grid systems
- Turn-based game flow
- Tactical movement and positioning
- Early combat and interaction mechanics

The emphasis is placed on clean logic, system design, and practical problem-solving within Unity.

---

## Goals

- Explore hex grid mathematics and navigation
- Practice structuring scalable gameplay systems
- Improve familiarity with Unity workflows and tooling
- Learn through building functional gameplay rather than isolated demos

Design decisions may evolve as systems are refined and knowledge improves.
